# Introduction 

The PRV PA (Pressure and Safety Relief Valves) sizing & selection Web Application helps the user to size and select the overpressure protection valves; Brands and Models which are supported in PRV Stand Alone Application are supported in PRV PA Web Application.

The PRV PA algorithms, calculations, codes / standards used, features, and products referenced are subject to constant change is maintained in Rule Engine and Emerson GOS.
